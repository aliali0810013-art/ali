# NineSoft Local UI Fast Preview

نسخة معاينة محلية بصرية أولية، وليست إصدار إنتاج أو تسليم Pixel-Perfect.

## الفرع وخط الأساس
- الفرع: local-ui-fast-preview
- نقطة البداية من ui-redesign: c8a12544221be0657e4145560d336753a4888652
- استرجاع تعديل جدول المشتريات من be153504be0d0695c33e69ee71ee381fbd439b4c بعد التحقق من تطابق محتوى الملف الأصلي.
- لم يتغير Laravel، أو قاعدة البيانات، أو عقود API، أو المزامنة، أو استضافة الإنتاج.
- لم يُدمج الفرع في main، ولم يُعد كتابة تاريخ ui-redesign.

## أسرع معاينة دون Flutter
افتح ملف preview/NineSoft-Local-UI-Fast-Preview.html في المتصفح مباشرة. فيه 20 شاشة تفاعلية للتنقل والتجربة البصرية باستخدام بيانات مؤقتة. الأزرار لا تحفظ أو ترسل عمليات مالية.

## تشغيل Flutter
إصدار Flutter المثبت في إعدادات CI الحالي: Flutter 3.47.9 stable.
في pubspec.yaml شرط Dart SDK هو ^3.12.0.

~~~bash
cd apps/nizami_app
flutter --version
flutter pub get
flutter run -d chrome -t lib/fast_preview/main.dart
~~~

Windows:
~~~bash
flutter run -d windows -t lib/fast_preview/main.dart
~~~

Android:
~~~bash
flutter devices
flutter run -d <DEVICE_ID> -t lib/fast_preview/main.dart
~~~

Build Web محلي:
~~~bash
flutter build web --release -t lib/fast_preview/main.dart
~~~

## ما تغيّر فعليًا
- تصميم وضع معاينة Flutter منفصل يتضمن 20 شاشة ذات أقسام وبطاقات وحقول وجداول مختلفة.
- واجهة تنقل مستقلة للهاتف والكمبيوتر.
- شاشة المشتريات الحقيقية: استرجاع جدول البنود المضغوط الآمن داخل purchase_workspace_page.dart دون تغيير المحرك المحاسبي.
- ملف HTML واحد مستقل يفتح مباشرة دون Flutter.

## ما لا يزال على الشكل القديم
- عند تشغيل نظام NineSoft العادي من lib/main.dart، لا تزال 19 شاشة من الشاشات المستهدفة على تخطيطها السابق؛ المعاينة الجديدة لا تحل محل مسارات التطبيق الحقيقية بعد.
- فاتورة المبيعات في التطبيق الحقيقي تستمر فيها تعديلات ui-redesign السابقة ولا تتغير في هذا الفرع إلا عبر المعاينة المستقلة.
- المعاينة ليست ربطًا حقيقيًا بين الصفحات العشرين وبيانات المنشآت.

# NineSoft 0.28.4 — اكتمال الصلاحيات والتقارير وفحص المستندات

- منع تعديل أو حذف السجلات المشتقة للديون والتقارير وحركات وتقييم المخزون، وربط أزرار الإضافة والتحرير والحذف بصلاحيات المستخدم الفعلية.
- تشديد عزل المستندات العامة حسب المؤسسة والفرع ومنع استبدال مستند معروف المعرّف عبر فرع آخر.
- إضافة صلاحيات عرض وإنشاء المستندات وصلاحية مستقلة لتعديل هوية الفرع المصرح به.
- إصلاح تجميع التقارير اليومية والمشتريات والنقد والمخزون وإشارات سندات الصرف ومنع احتساب التحصيل مرتين.
- إضافة عرض وتصدير فاتورة المشتريات بقالب A5 أفقي وهوية الفرع، والتحقق بصريًا من فاتورة مبيعات تحتوي 15 صنفًا في صفحة واحدة.
- إضافة فصل جلسة واتساب للفرع من التطبيق والخادم مع تأكيد واختبار عدم عبور الجلسات بين الفروع.
- استبدال حالة الخادم الثابتة بفحص جلسة حقيقي كل 30 ثانية، وإظهار انقطاع واتساب فور فشل فحصه.
- تمييز السجلات التشغيلية الأساسية التي لا ترحّل محاسبيًا داخل قوائم الأقسام لمنع تقديمها كوظائف دفتر مكتملة.

# NineSoft 0.28.3 — تدقيق عميق قبل النشر

- إضافة عكس آمن للقيد البسيط بدل حذفه، مع سبب إلزامي وسجل تدقيق وقيد عكسي متوازن.
- منع عكس القيد نفسه أكثر من مرة، ومنع عكس القيود الآلية من شاشة القيد البسيط.
- تطبيق صلاحية `invoices.delete` على عكس القيد مع عزل المؤسسة والفرع.
- تحسين بطاقة القيد للشاشات الضيقة حتى لا يخرج المبلغ أو وصف الحسابات من الإطار.
- نقل تحديث النسخة الاحتياطية التلقائية إلى طابور ما بعد الاستجابة لتسريع الحفظ.
- دمج مهام النسخ المتقاربة، وقفل إنشاء النسخة لكل مؤسسة، وقراءة لقطة قاعدة متسقة.
- إضافة جداول الطابور القياسية لتسجيل المهام الفاشلة وإتاحة تشخيصها.
- تجهيز توقيع Android الإنتاجي من `key.properties` مع إبقاء حزم PREPUBLISH موقعة تجريبيًا فقط.

# NineSoft 0.28.2 — ما قبل النشر

- إضافة شاشة قيد يومية بسيط موحّدة للويب وأندرويد وويندوز.
- اختيار حساب مدين وحساب دائن من شجرة حسابات الفرع وإدخال بيان ومبلغ واحد.
- منع ترحيل القيد غير المتوازن أو الحساب المكرر أو الحساب غير الفعال.
- حفظ القيد على الخادم مع عزل المؤسسة والفرع ومنع تكرار العملية وسجل تدقيق ومزامنة.
- عرض القيود اليدوية والآلية في سجل واحد وربطها بميزان المراجعة.

# NineSoft 0.8.0-dev.1

- واجهة وصول سريعة ملونة وقوائم للأقسام وساعة وتاريخ.
- شاشة قسم التحويلات WASL معربطة بـ NineSoft API فقط ومغلقة افتراضيًا.
- إعادة تحسين محرر الفواتير: لا معاينة PDF أثناء الكتابة، تنتهي بحفظ ومعاينة، ثم نموذج جديد.
- حفظ محلي تلقائي لبيانات العميل وحفظ الصنف/رقمه عند إضافة بند.
- توحيد مصادر العملاء والأصناف مع الأقسام، وتحسين توليد وحفظ الباركود المتسلسل.
- طبقة WASL Laravel للإضافة بعد مراجعة كود الخادم الحقيقي، ومخطط جداول مستقل.

تنبيه: إصدار للتطوير، لا يجوز نشره على الإنتاج أو اعتبار توافقه الكامل مثبتًا قبل `flutter analyze`, `flutter test` وتجربة Laravel على نسخة منفصلة.

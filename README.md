# NineSoft UI — Start Workspace

هذه نسخة واجهة NineSoft المبنية مباشرة فوق مشروع Flutter الحالي، مع الحفاظ على خدمات النظام ومسارات API والمزامنة والمحرك المحاسبي كما هي.

## ما الذي تغير؟

- شريط سفلي للكمبيوتر بأسلوب **Start / Taskbar** مع زر «ابدأ» وأيقونات صغيرة للأقسام الأكثر استخداماً والتبويبات المفتوحة.
- Dock للهاتف مع زر «ابدأ» يفتح مكتبة الأقسام.
- قائمة تطبيقات متجاوبة بأسلوب شبكات تطبيقات الهاتف، مع البحث والتصفية والمفضلة بالضغط المطول.
- قسم «تحرير سريع» داخل قائمة ابدأ يفتح المحررات الحقيقية: بيع F2، شراء F3، قبض F6، صرف F7، قيد F8، كشف حساب F9.
- الصفحة الرئيسية تعرض شبكة أقسام ملونة بأسلوب تطبيقات الهاتف، وإجراءات سريعة، ومؤشرات، ونشاطاً حديثاً، وتنبيهات، ورسم نشاط أسبوعي.
- تنظيم العرض إلى ست مجموعات: البيع والتحصيل، الشراء والسداد، المخزون، المحاسبة، التقارير، الإدارة.
- لا يوجد أي تغيير على Laravel أو قاعدة البيانات أو عقود API أو آلية الترحيل والمزامنة.

## التشغيل

```bash
cd apps/nizami_app
flutter pub get
flutter analyze
flutter test
flutter build web --release
```

للتجربة على جهاز متصل:

```bash
flutter run
```

## ملفات مهمة

- `IMPLEMENTATION_BRIEF_AR.md`: ضوابط التنفيذ والربط المحاسبي.
- `CHANGES_AR.md`: سجل التغييرات.
- `TEST_RESULTS_AR.md`: حالة الفحوصات في بيئة التسليم الحالية.
- `BACKEND_REQUESTS_AR.md`: يوضح إن كانت هناك متطلبات خلفية جديدة.

> هذه الواجهة لا تنشئ أرصدة أو قيوداً أو حركات مخزون من داخل العرض، بل تفتح المسارات والخدمات الموجودة في NineSoft كما هي.

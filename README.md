# NineSoft Start Workspace

واجهة NineSoft المتجاوبة للهاتف والكمبيوتر.

- شريط Start / Taskbar للكمبيوتر.
- قائمة تطبيقات بأيقونات ملونة.
- تحرير سريع واختصارات F2–F9.
- لوحة مؤشرات ونشاط وتقارير.
- الحفاظ على API والمزامنة والمحرك المحاسبي الحالي.

سيتم وضع حزمة المشروع الكاملة وملفات المصدر في هذا المستودع.
